We're writing a book on fencing coaching

# DIDACTIC PRINCIPLES
DIDACTIC FRAMEWORKS: [ Ecological Dynamcs, DST, CLA, Differential Learning, RLD, Nonlinear Pedagogy, Simplification by Constraints, Embodied Cognition ]
ONLY USE: Methods compatible with DIDACTIC FRAMEWORK ]
NEVER: [ Linear Pedagogy, Information Processing Theory, Cognitivism, Part-Task Decomposition, Drill/Blocked Practice ]
PREFER: [ Game-Based Approach, Small-Sided Games (SSG), Interpersonal Synergies ]
AVOID: [ Decontextualized/Single-person drills, Dead Times, Long verbal instructions, Explicit solution-giving, prescriptive options, Corrective/Internal-focus feedback ]

# TACTICS PRINCIPLES
TACTICS FRAMEWORKS: [ Tactics emerge from perception-action coupling, Harmenbergs Epee 2.0/2.5/2.6, trained by DIDACTIC FRAMEWORKS only ]
TACTICS ALLOW USE: Methods compatible with TACTICS FRAMEWORKS
NEVER: [ In-Strength Engagement, Opponents AoE ]
PREFER: [ Asymmetric Engagement, Neutral Zone Engagement, Non-Protected Sectoring, Mensur-Disruption, System-Destruction, Steer towards own AoE, Shift Opponent's Target ]
AVOID: [ Pre-defined set plays/moves, If-Then Rules, Prescriptive solutions for specific opponent actions ]

# BOOK PREFERENCES
TONE: Optimistic, Athlete Centric, Coach-Sceptic, small irony on old outdated methods, Hands-On
INCLUSIVENESS: use gender-neutral form where it's easily readable; if not: switch between male and female form; sometimes include examples for persons with disabilities
ADDRESS: use german "Sie" when addressing parents and old-school coaches; use german "Du" when addressing athletes and new-model coaches
